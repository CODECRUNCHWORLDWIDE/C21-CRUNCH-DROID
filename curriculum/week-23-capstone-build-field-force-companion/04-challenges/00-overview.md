# Week 23 — Challenges

One challenge this week, and it is the build week's whole point: lock the release candidate.

## Index

1. **[Challenge 1 — Lock the release candidate](./challenge-01-lock-the-release-candidate.md)** — assemble the signed `v1.0.0-rc1` AAB with R8 full mode and a verified Baseline Profile, get the full test suite green on CI, upload to the Play Console internal track, and write the four ADRs and the architecture diagram. The pre-submission audit must read all-PASS. (~2–4 hours, spread across Friday and Saturday)

This challenge is the build-week gate. When it is done, next week is delivery — chaos drills, closed-track submission, interviews — on a known-good artifact, not a build sprint. Do it Friday/Saturday so Sunday's audit can find anything you missed while there is still a week to fix it.
