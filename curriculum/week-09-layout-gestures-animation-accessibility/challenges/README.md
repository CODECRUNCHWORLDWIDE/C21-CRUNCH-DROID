# Week 09 — Challenges

The exercises drill basics. **Challenges stretch you.** This one takes 60–120 minutes and produces something you can commit to your portfolio and point at in an interview: a beautiful-but-broken component made operable by everyone, with a TalkBack walkthrough and a WCAG contrast report proving it.

## Index

1. **[Challenge 1 — Make an inaccessible component accessible (and prove it)](challenge-01-inaccessible-then-fixed.md)** — take a gesture-only, low-contrast custom component that's invisible to TalkBack, audit it (TalkBack walkthrough + contrast ratios + touch-target check), fix it to full accessibility (semantics, custom actions, merged stops, 48dp targets) and WCAG AA contrast, and document the before/after with a TalkBack transcript and a contrast table. (~90 min)

Challenges are optional. If you skip them, you can still pass the week. If you do this one, you'll be measurably ahead — and "I found a swipe-to-delete that a blind user literally couldn't use, and here's the before/after TalkBack transcript and the contrast fix" is the kind of concrete, humane, senior win that lands in code reviews and interviews. The accessibility-by-default instinct you build here is a hiring signal at every serious mobile team, and it reappears in Phase III's testing week as automated accessibility checks in CI.
