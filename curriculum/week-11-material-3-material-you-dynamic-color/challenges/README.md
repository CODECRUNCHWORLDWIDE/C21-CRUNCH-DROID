# Week 11 — Challenges

The exercises drill basics. **Challenges stretch you.** This one takes 60–120 minutes and produces something you can commit to your portfolio and point at in an interview: a measured accessibility fix.

## Index

1. **[Challenge 1 — Audit a theme for contrast, then fix the failing pair](challenge-01-contrast-audit-then-fix.md)** — take a theme (yours, or a deliberately weakened one), compute WCAG contrast ratios for every important role pair in both light and dark, find the pair that falls below 4.5:1 (body) or 3:1 (large/UI), fix it by moving a tonal value, and document the before/after ratios with the math. (~90 min)

Challenges are optional. If you skip them, you can still pass the week. If you do this one, you'll be measurably ahead — and "I found a 3.8:1 contrast failure in our dark theme's secondary text and fixed it to 4.6:1, here's the audit" is the kind of concrete, quantified accessibility win that lands in code reviews and interviews. The "measure, don't eyeball" instinct you build here reappears in Phase 3's performance and testing weeks, where the same discipline applies to timings and screenshots.
